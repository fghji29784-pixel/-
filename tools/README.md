# 셀 매칭 · 샘플링 도구 (`matching_tool.html`)

서버가 필요 없는 **단일 HTML 파일**입니다. 엑셀 파싱 라이브러리가 파일 안에 내장되어
있어서, 인터넷이 안 되는 사내망에서도 더블클릭으로 브라우저에서 바로 열립니다.
파일은 브라우저 메모리 안에서만 처리되고 외부로 전송되지 않습니다.

## 사용법

1. `matching_tool.html`을 더블클릭해서 브라우저(엣지/크롬)로 엽니다.
2. **원본 파일**(Cell ID, 등급, Cell No, Cell 위치, OCV 값들이 있는 엑셀)과
   **출력 파일**(CELL_ID, PROBA_case0/1/11이 있는 메인코드 결과 엑셀)을 각각 선택합니다.
   (메인코드는 이 도구가 실행하지 않습니다 — 평소처럼 직접 돌려서 나온 출력 파일을 쓰세요.)
3. "매칭 실행" 클릭 → 원본(Cell ID) = 출력(CELL_ID) 기준으로 자동 매칭, docv7
   (= PRIVT OCV #01 OCV − PRIVT OCV #03 OCV) 계산.
4. NG 판정 기준값(case0/1/11)과 등급 A 관련 기준값(필수/후보3)을 필요하면 조정합니다.
   바꾸면 판정·요약·샘플링 후보가 바로 다시 계산됩니다.
5. 샘플링 후보 표에서 체크박스로 최종 리스트를 조정합니다.
   - **필수** 항목(판정 혼재, 등급 A + proba ≥ 필수기준)은 체크 해제할 수 없습니다.
   - 후보1/2/3은 기본으로 체크되어 있고, 필요 없으면 해제할 수 있습니다.
   - 후보 표 상단의 "표시할 후보 유형" 체크박스로 후보1/2/3 자체를 통째로 빼거나 넣을 수
     있습니다 (예: 후보가 너무 많으면 후보3만 꺼서 줄이기). 필수 항목은 항상 포함됩니다.
   - 후보가 된 이유는 별도 칼럼이 아니라, 원인이 된 칸 자체에 색이 칠해져 표시됩니다
     (예: docv7 때문이면 docv7 칸이 색칠됨). 마우스를 올리면 정확한 이유가 뜹니다.
   - 기준값을 바꾸거나 후보 유형을 껐다 켜도, 직접 체크/해제한 선택은 유지됩니다.
6. 후보 표(4번)와 샘플링 리스트(5번)는 각 컬럼 헤더를 클릭하면 오름차순/내림차순
   정렬되고, 헤더 바로 아래 입력창에 검색어를 넣으면 필터링됩니다. 숫자 컬럼은
   `>=0.5`, `<16` 처럼 부등호를 넣어 필터링할 수 있습니다. 이 필터는 화면 표시에만
   영향을 주고, 실제 선택된 샘플링 리스트나 다운로드 결과는 바뀌지 않습니다.
7. 하단 "전체 매칭 결과"는 **매칭됨 / 미매칭** 두 탭으로 나뉘어 있고, 매칭됨 탭에서
   샘플링 리스트에 포함된 행은 노란색으로 강조됩니다. 미매칭 탭은 원본에서 같은
   Cell ID를 찾지 못한 셀만 모아 보여줍니다 (판정·후보 계산에는 그대로 포함됨).
8. "결과 엑셀 다운로드"를 누르면 `매칭결과 / 요약 / 샘플링리스트` 3개 시트가 담긴
   엑셀 파일이 다운로드됩니다. (표시 필터와 무관하게 실제 선택된 전체 항목이 포함되고,
   화면의 셀 색상 표시도 엑셀 셀 배경색으로 그대로 들어갑니다.)

## 대용량 데이터 (수만~수십만 행)

10만 행 기준으로 확인한 성능입니다.

- 매칭 + 판정 + 화면 표시: 약 10~15초
- 스크롤/정렬/필터: 실제로는 화면에 보이는 30~40행만 그리기 때문에 거의 즉시 반응
- 결과 엑셀 다운로드(셀 색상 포함): 약 15~20초

표는 전체 데이터를 한 번에 그리지 않고 스크롤 위치에 따라 필요한 부분만 그리는
방식(가상 스크롤)이라, 행이 아주 많아도 화면이 느려지지 않습니다. 다만 매칭 실행과
다운로드는 계산량이 많아 몇 초~몇십 초가 걸릴 수 있고, 그동안 버튼에 "생성 중..."
같은 문구가 표시됩니다.

## 후보 유형별 건수 · 전체 선택/해제

샘플링 후보 표 위에 "필수 X건 · 후보1 Y건 · 후보2 Z건 · 후보3 W건"처럼 유형별
건수가 표시됩니다 (한 행이 여러 유형에 동시에 해당할 수 있어 합계와 후보 전체
건수가 다를 수 있습니다). "표시된 행 전체 선택 / 전체 해제" 버튼으로 현재
필터링된 후보들을 한 번에 체크하거나 해제할 수 있습니다 (필수 항목은 항상 유지).

## CELL_ID 중복 처리

출력 파일 자체에 같은 CELL_ID가 여러 번 있으면, 그 행들을 하나로 합치지 않고
각각 별도 행으로 매칭·표시합니다 (즉, 4/5번 표에 같은 CELL_ID가 여러 번 나올 수
있습니다). 대신 매칭 실행 직후 몇 건이 중복인지 화면에 경고로 표시해 드립니다.
원본 파일 쪽에 중복된 Cell ID가 있으면 마지막 행 값으로만 매칭되며, 이 경우도
경고가 표시됩니다.

## 판정/후보 기준 (기본값)

- PROBA_case0 ≥ 0.45 → NG, PROBA_case1 ≥ 0.5 → NG, PROBA_case11 ≥ 0.5 → NG
- **필수 포함**: ① 세 판정이 서로 다른 셀(NG/OK 혼재) ② 원본 등급 A인데 세 PROBA 중
  하나라도 0.4 이상인 셀
- **후보1**: 등급 E인 셀들 중 docv7 최솟값보다 docv7이 큰, 등급 A인 셀
- **후보2**: |PROBA_case11 − PROBA_case0|가 큰 상위 16개 셀
- **후보3**: 원본 등급 A인데 세 PROBA 중 하나라도 0.2 이상인 셀

모든 기준값은 화면에서 직접 수정할 수 있습니다.

## 필요한 컬럼

- 원본 파일: `Cell ID`, `등급`, `Cell No`, `Cell 위치`,
  `PRIVT OCV #01 OCV`, `PRIVT OCV #02 OCV`, `PRIVT OCV #03 OCV`
- 출력 파일: `CELL_ID`, `TRAY_ID`, `LOT_ID`, `PROBA_case0`, `PROBA_case1`, `PROBA_case11`

컬럼이 없으면 업로드 후 어떤 컬럼이 빠졌는지 화면에 바로 표시됩니다.

## 배포 방법

파일 하나(`matching_tool.html`)만 이메일이나 사내 공유폴더로 전달하면 됩니다.
받는 사람은 설치할 것 없이 더블클릭해서 바로 사용할 수 있습니다. (Internet Explorer는
지원하지 않습니다 — Edge, Chrome 등 최신 브라우저를 사용하세요.)
